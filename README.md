# 바르셀로나 한인 비즈니스 지도

카탈루냐 한인회에서 제공하는 바르셀로나 한인 업체와 장소 65곳 지도입니다.

- 업체 이름: 영문(한글)
- 업종에 따른 지도 아이콘
- 모바일 화면 지원
- 업종별 필터와 업체명·주소 검색
- 업체 카드, 전화, 웹사이트, Google 지도 사진·리뷰와 길찾기
- 사용자가 위치 권한을 허용하면 가까운 순으로 정렬 (직선거리)
- 카카오톡 Koreanbcn 제보 안내

[Google 지도 열기](https://www.google.com/maps/d/viewer?mid=11Oh1D7WD_zCbgVHFe19dcBNYHgOxUuM)

[지도 웹사이트](https://stylejuya.github.io/barcelona-korean-map/)

지도는 Leaflet과 OpenStreetMap으로 표시합니다. `places.js`는 원본 지도에서 가져온 업체 정보이며, 원본 변경 시 다시 갱신해야 합니다. 현재 위치는 서버에 저장하지 않고 브라우저에서 거리 계산에만 사용합니다. 사진과 리뷰는 Google 지도에서 열립니다.

## GitHub Pages

저장소의 Settings → Pages에서 Deploy from a branch를 선택한 뒤 main 브랜치의 /(root)를 지정합니다.

원본 지도는 방문자가 볼 수 있는 공유 설정이어야 합니다.

2026-10-10: 제공된 2026 PDF 목록과 대조해 21곳을 추가했습니다. 교육·문화와 여행 분류를 추가했습니다. Konggan, Barna Tour, Bondia Tour는 PDF 기재 주소 좌표를 사용하며 카드에서 이를 안내합니다. Ondo는 사용자 요청으로 이번 추가에서 제외했습니다. 소나무 연락처는 공식 웹사이트 기준입니다. 초기 화면은 바르셀로나 시내이며 전체 지도 보기에서 근교 전체를 확인할 수 있습니다.
